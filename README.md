# Developer Career & Recruitment Landing Page

A modern, high-impact corporate landing page designed to attract, inform, and recruit top engineering talent by highlighting company culture, tech stacks, and open developer roles.

## 🎯 Why I Built This
I created this project to practice corporate-level web design and technical landing page structure. My focus was on creating a highly professional aesthetic with precise typographic hierarchy and clean layouts that effectively communicate employer branding and engineering values to potential candidates.

## ✨ Key Features
* 🛠️ **Tech Stack & Architecture Showcase:** A clean visual grid highlighting the company's core technologies, engineering practices, and developer tooling.
* 📈 **Perks & Culture Grid:** An organized layout detailing developer-centric benefits, such as remote flexibility, learning budgets, and engineering mentorship programs.
* 💼 **Open Positions Board:** A beautifully structured list filtering current open roles by department, experience level, and location.
* 📱 **Mobile-Optimized Experience:** A fully responsive layout ensuring a seamless browsing and application experience across both desktop and mobile devices.

## 🛠️ Tech Used
* Semantic HTML5 (Main, Sections, Articles, and Nav elements)
* Custom CSS3 (Flexbox & CSS Grid for structured multi-column dashboards)
* Advanced CSS Styling (Clean button components, link hover animations, and subtle drop shadows)
* Responsive Web Design (Media Queries for seamless cross-device compatibility)
